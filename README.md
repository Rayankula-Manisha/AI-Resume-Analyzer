# AI-Resume-Analyzer
## AI Resume Analyzer 🎯

An AI-powered Resume Analyzer built using Python and Streamlit to help job seekers evaluate their resumes against specific job roles. The application analyzes job similarity, identifies matching and missing skills, evaluates resume quality, and recommends relevant courses and learning resources to improve employability.

### Features
- 📄 PDF resume text extraction
- 🎯 Job description and resume similarity analysis
- 🧠 Matching and missing skill identification
- 📊 Interactive charts and visual analysis
- 📝 Resume quality and improvement suggestions
- 🎓 Personalized course recommendations with clickable learning links
- 🗺️ Skill-based learning roadmap
- 📚 Official documentation and learning references
- ⬇️ Downloadable analysis reports and course recommendations

### Technologies Used
Python, Streamlit, Pandas, Plotly, PDFPlumber, Scikit-learn, and Groq API (for AI-powered suggestions, when configured).

**Goal:** Help job seekers understand their skill gaps and prepare more effectively for their target careers.
